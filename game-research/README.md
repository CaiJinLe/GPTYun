# 生活模拟游戏数值研究

## 研究目标与协作方式

以《星露谷物语》训练数值体验分析，以《心动小镇》训练长线运营观察。日常记录保持轻量，专题分析再深入。

- 先由记录者独立分析，再通过追问完善思路，不预先给出全部答案。
- 区分个人观察、主观感受、机制假设、外部资料和验证结论。
- 静态数据可以查询可靠资料，但必须记录来源、适用版本与查询日期；未经核实不写成事实。
- 不虚构游戏数据、玩家行为、留存率或付费率。个人游玩观察不代表整体玩家数据。
- 已有项目深挖在其他对话进行，待提供结果，不重复要求开展。
- 文件修改前检查已有内容；追加记录，保留原始表述。修订或验证结果另行注明，不静默改写原始观察。
- 正式记录改用本仓库，不再以腾讯文档为写入目标。提交后须核对远端文件，报告路径和提交信息。

## 两条研究主线

### 星露谷物语

平台及版本：Switch，1.6.15.13。关注时间与体力、农业经济、玩法收益与成本、技能及工具效率、阶段目标与季节解锁、加工链及投资回收。

目标：从实际体验发现问题，区分机制和感受，提出设计目标解释与优化假设，再通过模型或实验检验，最终独立完成数值体验分析。

### 心动小镇

关注新手与开放节奏、每日任务及负担、资源与成长周期、每周及版本活动、长期目标、家园与收集社交，以及外部奖励和内在兴趣的关系。

## 记录约定

游戏内日期与现实记录日期分开。未提供的日期、存档年份及测量方法不补造。数值库中的来源类型和验证状态不得省略；原始日志中的数字不自动成为已验证机制。
